Vocabulary Memory Enhancement in Multimodal Learning Environments

Zhejiang Normal University · Ongoing

Overview

This study examines how working memory and positive emotion interact to enhance vocabulary retention in Chinese language learners in a multimodal environment — from a psychological perspective.

Language acquisition is a cognitively demanding process. Understanding the psychological mechanisms that facilitate or impede vocabulary encoding can directly inform more effective instructional design.

Background

Multimodal learning environments — combining visual, auditory, and kinesthetic inputs — have gained traction as effective settings for language acquisition. However, the cognitive and affective mechanisms underlying their effectiveness are less well understood.

Working memory plays a central role in holding and processing new lexical items. Positive emotion, meanwhile, has been shown to broaden attentional scope and facilitate encoding. This study investigates their interaction in a real-world learning context.

Project Development

Step 1

Theoretical Framework

Grounded in Baddeley's working memory model and Fredrickson's broaden-and-build theory of positive emotion.

  • Literature review on working memory and language learning
  • Review of emotion-cognition interaction research
Step 2

Study Design

Designed experimental task to isolate working memory load and emotional induction conditions.

  • Developed Chinese vocabulary learning task
  • Adapted emotion induction protocol
  • Validated materials with pilot participants
Step 3

Data Collection & Analysis

Collected data from participants in multimodal learning sessions. Analysis underway.

  • Administered working memory assessments
  • Used R for statistical analysis
  • Mixed ANOVA and mediation modeling
